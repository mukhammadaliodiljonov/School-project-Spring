# School Project – Spring Backend Application

## About This Project
This is a Java backend project I built for school.  
It’s designed to show how a real backend works, with APIs, database integration, and clean architecture using the Spring Framework.

## What It Does
- Provides a REST API to manage application data
- Supports create, read, update, and delete operations (CRUD)
- Follows a layered structure: Controllers, Services, Repositories
- Handles errors and validates data
- Saves data to a database

## Technologies Used
- Java
- Spring Framework (MVC, Data JPA)
- Hibernate
- Maven
- Database: MySQL / PostgreSQL (or H2 for testing)
